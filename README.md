# 🚀 D&A Global OS

El sistema operativo rápido, bonito y en español.

- **Escritorio KDE Plasma**, moderno y fácil de usar
- **IA integrada** que funciona sin internet
- **Programas de Windows** (.exe) y **apps de Android**
- **Se actualiza con un clic** desde Discover, sin reinstalar nunca

Versión actual: **26.04.1**

## Activar las actualizaciones

Los equipos instalados con la ISO más reciente ya las reciben. En un equipo
instalado antes, abre una terminal y escribe:

```
curl -fsSL https://DavidAPF.github.io/D-A-Global-OS/instalar.sh | sudo bash
```

Este repositorio contiene los paquetes firmados de D&A Global OS para apt.
